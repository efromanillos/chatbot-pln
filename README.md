## Descripción del proyecto
Este proyecto implementa un **chatbot basado en técnicas clásicas de Procesamiento del Lenguaje Natural (PLN)**.  
El objetivo es permitir que el bot responda preguntas basadas en uno o varios **documentos PDF**, utilizando métodos de recuperación de información.

El chatbot **no utiliza modelos generativos**, sino técnicas tradicionales como:

- Limpieza y normalización de texto
- División del documento en fragmentos (chunking)
- Representación vectorial mediante **TF‑IDF**
- Procesamiento lingüístico con **spaCy**
- Cálculo de similitud mediante **coseno**
- Recuperación de los *k* fragmentos más relevantes (top‑k retrieval)
